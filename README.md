# samihalawa/tap

Homebrew tap.

| Cask | What it is |
|---|---|
| [`postura`](https://github.com/samihalawa/postura) | macOS menu bar posture guard: a glow covers the screen when you slouch, on-device camera |
| [`autohotspot`](https://github.com/samihalawa/mac-auto-hotspot) | macOS menu bar app that joins your iPhone Personal Hotspot automatically when Wi-Fi drops |

```sh
brew tap samihalawa/tap
brew install --cask autohotspot
brew install --cask postura
```
